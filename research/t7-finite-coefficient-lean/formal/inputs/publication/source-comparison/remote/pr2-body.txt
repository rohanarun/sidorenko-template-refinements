## Method

The earlier bounds count the $m$ active pair spaces as free two-dimensional subspaces of the global span. The paper's own **direct-case** count is sharper: it places one basis vector at a time, and each new vector must be symplectically orthogonal to everything already placed at either endpoint. This PR runs that count for the nondirect case too:

- each basis vector records whether it raises the global span and whether it raises each endpoint span (type $(g,\ell_i,\ell_j)$, with $\ell\ge g$);
- the defect $d=\sum_i k_i-2k$ is exactly the number of vectors that raise a local span without raising the global one;
- the identity $\sum_i\binom{k_i}{2}=\sum_x\sum_{\ell=1}v'_i(x)$ cancels the containment cross terms, leaving $R=-2m+\sum\pi_x+(\text{defect terms})$ where $\pi_x$ is the overlap of the two endpoint spans;
- averaging $\pi\le\tfrac12(v'_i+v'_j)$ per vertex and using concavity gives $R\le\sum_i\deg(i)^2-3m+\lfloor(k_i+k_j-1)/2\rfloor=262-84+11=189$ for $d=1$, and $R/d\le122$ for $d\ge2$.

In the direct case the same accounting reproduces the paper's exact exponent $-m$, which is a useful consistency check.
